# Audio credits

Every file in this folder was synthesized for Capy Tower Wars by `tools/make_audio.py`. There are no third-party recordings or samples in the sounds.

The generator uses only math (tones, envelopes, and a little filtered noise). You can rebuild the WAVs by running:

```bash
python3 tools/make_audio.py
```
