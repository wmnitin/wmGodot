# Model credits

The match uses low-poly meshes from CC0 packs. Audio in `assets/audio/` is credited separately in `assets/audio/CREDITS.md`.

Models copied from the fan mirror [trebeljahr/quaternius-showcase](https://github.com/trebeljahr/quaternius-showcase) (`public/glb/`), which redistributes the CC0 packs. Upstream pages:

| Used for | File | Pack |
| --- | --- | --- |
| Tank | `assets/models/quaternius/Tank.glb` | [Animated Tanks](https://quaternius.com/packs/animatedtanks.html) |

The Google Drive zips linked from quaternius.com returned "Quota exceeded" on this run, so the GitHub mirror above was used instead. Poly Pizza hosts the same tank pack as CC0: https://poly.pizza/bundle/Animated-Tank-Pack-0tfvbeAJkU

## Capybara (CC0)

`assets/models/cc0/capybara.glb` — capybara with a barrel body and short legs, from [3DAssets.dev](https://3dassets.dev/assets/rainforest-and-jungle-fauna-capybara-8d6c2ccd), [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). Direct file: `https://cdn.3dassets.dev/assets/21668/v1/model.glb`.

Kenney's Animal Pack Remastered is 2D sprites and has no capybara. Quaternius Ultimate Animated Animals (alpaca, fox, wolf, and the rest of that pack) has no capybara. The capybara on Poly Pizza's Animals bundle is CC BY 3.0, so it was not used.
